Programming in the words you already speak.

NepLang is a programming language with Nepali keywords. Write vana to print, yedi for if, kaam for a function.

A small language with real tools

      

        

          
Errors you can understand

          
Every error names the line, points at the exact spot, and says how to fix it: Did you mean 'umar'?

        

        

          
Checked before it runs

          
neplang check finds undefined names, wrong argument counts and type mistakes without running anything.

        

        

          
Classes and types

          
Classes, inheritance, interfaces, typed variables like int umar = 22, and a standard library for math, text, arrays and files.

        

        

          
From script to program

          
Run a file directly, try lines in the REPL, or turn a program into a fast native executable with neplang build.
