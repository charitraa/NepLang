Download NepLang

The latest release, for Windows, macOS and Linux.

Windows

Open PowerShell and run:

irm https://raw.githubusercontent.com/charitraa/NepLang/main/install.ps1 | iex

Then open a new terminal window and check it with neplang --version.

Windows

Installer script

In PowerShell. It installs to %LOCALAPPDATA%\Programs\neplang and adds it to your PATH.

irm https://raw.githubusercontent.com/charitraa/NepLang/main/install.ps1 | iex

Scoop

scoop bucket add neplang https://github.com/charitraa/scoop-neplang
scoop install neplang

winget

winget install charitraa.NepLang

The winget package is waiting for review by the winget team. Until it is published, use the installer script or Scoop.

By hand

Download neplang-windows-x86_64.exe, rename it to neplang.exe and put it in a folder on your PATH.

macOS

Installer script

Works on Apple silicon and Intel Macs. It installs to ~/.local/bin.

curl -fsSL https://raw.githubusercontent.com/charitraa/NepLang/main/install.sh | sh

Homebrew

brew install charitraa/neplang/neplang

By hand

Download neplang-macos-universal, then chmod +x it and move it to a folder on your PATH.

Linux

Installer script

For x86_64 and arm64. It installs to ~/.local/bin.

curl -fsSL https://raw.githubusercontent.com/charitraa/NepLang/main/install.sh | sh

Ubuntu, Debian, Linux Mint

Download the .deb for your machine from the list below, then:

sudo apt install ./neplang_*_amd64.deb

Fedora, RHEL

sudo dnf install ./neplang-*.x86_64.rpm

Arch, Manjaro, CachyOS

git clone https://github.com/charitraa/NepLang.git
cd NepLang/packaging/arch && makepkg -si

Homebrew on Linux

brew install charitraa/neplang/neplang

Optional: neplang build

Running programs needs nothing else. Only neplang build, which makes a standalone executable, also needs a C compiler: gcc on Linux, xcode-select --install on macOS, or MSYS2 with mingw-w64-ucrt-x86_64-gcc on Windows.

Build from source

You need git, make and a C compiler.

git clone https://github.com/charitraa/NepLang.git
cd NepLang
make
sudo make install

Update or uninstall

To update, run the same install command again. To remove NepLang, delete ~/.local/bin/neplang (Linux and macOS) or the %LOCALAPPDATA%\Programs\neplang folder (Windows), or use your package manager: scoop uninstall neplang, brew uninstall neplang, sudo apt remove neplang.
